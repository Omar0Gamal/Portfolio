# Omar Gamal - Portfolio

Source code for my personal portfolio website, built with **Next.js 15**, **TypeScript**, and **Tailwind CSS**. 

## Overview
This repository contains the frontend implementation of my portfolio, designed to be clean, fast, and maintainable. It highlights my experience in backend systems, distributed architecture, and open-source contributions.

### Tech Stack
- **Framework**: Next.js 15 (App Router)
- **Language**: TypeScript
- **Styling**: Tailwind CSS
- **Icons**: Lucide (via `react-icons`)
- **Animations**: Framer Motion & custom CSS
- **Deployment**: Vercel

## Local Development

First, install the dependencies:
```bash
npm install
```

Then, run the development server:
```bash
npm run dev
```

Open [http://localhost:3000](http://localhost:3000) with your browser to see the result.

## Project Structure
- `/app` - Next.js App Router layout and pages
- `/components` - Reusable React components (Hero, Projects, Experience, etc.)
- `/data` - Structured content (TypeScript files) for education, experience, and projects
- `/public` - Static assets (images, CV, icons)
- `/lib` - Utility functions (e.g., markdown parser for articles)
